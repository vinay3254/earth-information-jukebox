# Frame Lab Audio Credits

The audio assets in `public/audio/lab/samples/` are sourced from the open-source `tonejs-instruments` repository curated by Nicholas Brosowsky, which adapts public domain and Creative Commons orchestral samples:

- **Harp** (`samples/harp/`): Versilian Studios Chamber Orchestra 2 Community Edition (VSCO 2 CE). Creative Commons 0 (CC0) / Public Domain.
- **Xylophone** (`samples/xylophone/`): Versilian Studios Chamber Orchestra 2 Community Edition (VSCO 2 CE). Creative Commons 0 (CC0) / Public Domain.
- **Flute** (`samples/flute/`): Versilian Studios Chamber Orchestra 2 Community Edition (VSCO 2 CE). Creative Commons 0 (CC0) / Public Domain.
- **Cello** (`samples/cello/`): Freesound (pack 12408 by flcellogrl), edited and normalized in `tonejs-instruments`. Creative Commons Attribution 3.0 (CC-BY 3.0).
