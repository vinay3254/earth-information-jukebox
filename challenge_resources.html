NASA Data & Resources

Earth Information Center (EIC) Content Database: This is a set of visuals developed by the Scientific Visualization Studio (SVS) that is used in the EIC dashboards. Participants can use the videos and images as data for processing the audio files.

Data Sonification: Caldwell 73: This visualization demonstrates how NASA converts astronomical imagery into auditory experiences. Although it utilizes deep-space data, it provides an excellent conceptual framework for how visual attributes like luminosity and spatial coordinates can be effectively translated into musical volume and pitch.

Change in Night Lights between 2012 and 2023 - EIC Version: This visual tool tracks the evolution of urban illumination across the globe. The high contrast between dark terrain and brilliant light provides a perfect testing ground for computer vision algorithms that map intensity to audio tempo or volume.

Global Sea Surface Currents and Temperature: These animations illustrate the fluid movement of ocean currents alongside thermal gradients. This is a premier for teams aiming to convert continuous, flowing motion and shifting temperature data into complex, evolving soundscapes.

GEOS Aerosols: This visualization monitors the path of smoke, dust, and other atmospheric particles, categorized by type. It is excellently suited for multi-track experimentation, where different visual layers can be assigned unique audio textures or musical instruments.

Air Quality Model Runs: Sourced from the Scientific Visualization Studio, these downloadable high-resolution frames represent atmospheric data models. Teams can utilize these individual images to algorithmically convert color palettes and pixel densities into dynamic sound profiles.

Perpetual Ocean 2: Western Boundary Currents: This dataset provides striking visual maps of major oceanic boundary currents. Because the imagery is high contrast, it is extremely useful for processing via computer vision to align visual shifts with specific musical rhythms or scales.

DYAMOND Global Carbon Dioxide: Showcasing global CO2 concentrations, this allows participants to observe changing visual patterns over time. This data can serve as a primary input for driving the interactive audio synthesis within an \"Earth Jukebox\" tool.

Lightning Events Detected from the ISS 2017-2023: This compilation of lightning data detected from space offers intricate, layered visuals. It is uniquely suited for punctuated sonification, where percussive elements or sudden audio triggers correspond to the rapid visual flashes of lightning.

A 3D View of an Atmospheric River from an Earth System Model: This 3D visualization follows the path of an atmospheric river. Participants can extract individual frames to experiment with mapping the density and geographic spread of moisture into immersive and shifting musical landscapes.

GEDI Forest Height: Featuring global maps of canopy elevation, this dataset is ideal for participants looking to map diverse color spectrums—which signify varying forest heights and densities—to dynamic audio parameters such as rhythm, frequency, or pitch.
